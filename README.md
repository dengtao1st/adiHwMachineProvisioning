# adiHwMachineProvisioning

Source code for an iOS device provisioning and MobileGestalt research project.

## Contents

- `src/`: Objective-C, Objective-C++, and supporting headers
- `frida/`: Frida instrumentation script

Local deployment configuration, signing entitlements, device-specific property lists, build outputs, and the original deployment Makefile are intentionally excluded from this public source snapshot because they contain credentials or machine-specific settings.

Third-party components retain their upstream notices where provided.
